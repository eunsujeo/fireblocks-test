원문에서 확인이 필요한 부분

아래는 문서를 재구성하며 발견한 확인 사항이다. 설계 본문을 수정하거나 현재 구현 여부를 판정한 결과는 아니다.

동기 요청과 이벤트 처리의 실패 경계

p.4는 서비스 → DAW코어 → DAWBC의 동기 호출과 큐를 통한 이벤트 전달을 구분한다. p.19는 롤백 난이도에 따라 처리 순서를 정한다. 응답 유실·재시도·중복·역순 처리와 시스템 간 롤백 구현 방식은 명시하지 않는다.

외부브릿징중의 해제 시점

개별 확정과 정산 전체 완료

p.11·50은 모든 BCTX가 확정되기 전 대기 금액을 유지한다고 설명한다. p.52는 정산내역·델타원장·자산별 잔고 갱신과 대기 해제를 하나의 도식에 표시하므로, 순번별 실행 조건을 구체화할 필요가 있다. p.50의 SC통화 업데이트 표현과 p.52의 자산별 갱신 대상도 대조 대상이다.
