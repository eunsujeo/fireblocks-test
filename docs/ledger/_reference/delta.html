델타원장과 정산내역

SC통화 소유권 변경과 회사·고객 간 실제 자산 이동 사이의 정산할 수량을 기록한다.

원문 p.7p.50p.51p.52

DAW코어

SC통화 소유권 변경과 회사·고객 간 실제 자산 이동 사이의 정산할 수량을 기록한다.

항목정의
델타원장 키원거래TID(PK) + SC통화(PK).
정산TID미정산일 때 빈칸(''). 정산중·정산완료일 때 정산 트랜잭션 TID를 기입한다.
TO · 수량TO는 받는 상대방: KB 또는 USER. 수량은 해당 상대에게 정산할 수량.
상태미정산 → 정산중 → 정산완료.
정산내역 키TID(PK) + SC통화(PK) + txHash(PK). 한 TID에 여러 txHash가 생길 수 있다.
정산내역 Type정산시작 또는 정산완료. 거래내역의 append-only 원칙에 대한 명시적인 예외로 Type 업데이트를 허용한다.
정산 전체 완료같은 TID의 모든 BCTX가 확정된 시점과 개별 BCTX 확정을 구분한다. 먼저 확정된 금액은 주소별 잔고의 델타정산입금대기·델타정산송금대기에 기록한다.
