### 계약 변경

- **Wallet API의 인증이 레퍼런스에 API 키로 표시됩니다.** 그동안 레퍼런스가 이 표면을 bearer
  토큰으로 광고했지만, 실제로 받는 것은 `X-API-KEY` 헤더에 실린 파트너사 API 키입니다. 서버
  동작은 처음부터 API 키였으므로 부르시던 방식은 바뀌지 않습니다. 레퍼런스의 「Authorize」와
  생성되는 클라이언트 코드만 이제 실제 동작과 같아집니다. → [인증과 스코프](/start/authentication)
