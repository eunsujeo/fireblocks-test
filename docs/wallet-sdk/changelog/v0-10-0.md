### 문서

- **정책 엔진 탭에 [전체 지도](/policy/map)를 새로 냈습니다.** 저작 산출물이 가는 경로(번들 탑재 ·
  빌드 전용 · 런타임 조립)과 평가 입력 문서의 조립을 다이어그램 두 장과 표 하나로 요약했습니다.
  각 조각의 정의는 기존 소유 페이지가 그대로 들고, 지도는 첫 진입점입니다.
