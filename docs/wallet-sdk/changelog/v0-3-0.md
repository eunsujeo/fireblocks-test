### 문서

- **제품 탭이 없어졌습니다.** 제품 소개·이용 대상·두 자격은 [홈](/)이, 제공 범위는
  [시작하기](/start)가, 에코시스템은 [시작하기 아래](/start/ecosystem)가 맡습니다. 같은 주장이
  홈·제품·시작하기 세 자리에 되풀이돼 있어 하나로 모았습니다 — 대신해 주는 셋, 수탁 두 층,
  스코프는 인증이 정한다, 부르는 표면은 하나.
- **「표면 다섯 개」가 [표면과 인증](/start/authentication)으로 합쳐졌습니다.** 누가 무엇을 부르는지와
  무엇이 인증에서 나오는지가 한 페이지입니다.
- **옛 주소는 그대로 열립니다.** `/product`·`/product/audience`·`/product/boundary`·
  `/product/ecosystem`·`/start/surfaces`가 새 자리로 넘어갑니다. 북마크를 고치실 필요는 없고,
  새로 거는 링크는 새 주소로 걸어 주십시오.
- **구현 대기가 열린 PR도 읽습니다.** `main`만 보면 아직 머지되지 않은
  구현이 전부 「계약만」으로 나왔습니다. 이제 상태가 넷입니다 — 동작 · 모형 응답 · **구현 PR
  열림** · 계약만. 「구현 PR 열림」은 그 PR이 머지되기 전까지 부르면 여전히 `404`입니다.
- **태그마다 `main` 반입 PR이 자동으로 열립니다.** 머지는 사람이 합니다. 그 PR 본문이 판정 재료를
  링크합니다.
- **`docs/site/AGENTS.md`가 생겼습니다.** 문서를 고칠 때의 규율이 README에 섞여 있던 것을 떼어
  기준으로 세웠습니다 — 한 주장은 한 페이지가 소유한다는 규칙이 여기서 시작합니다.
