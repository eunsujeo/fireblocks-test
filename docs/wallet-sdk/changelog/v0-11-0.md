### 계약 변경

- **초안 검증 응답의 위반 항목에 `why` 칸이 생겼습니다.** `message`는 무엇이 어긋났고 어느 방향으로
  고치는지만 100자 이내로 말하고, 그대로 두면 무슨 일이 나는지는 `why`로 갈라 실립니다. 컴파일 검사가
  낸 위반에만 값이 있고 그 밖은 `null`입니다. `target`은 `key=value`를 공백으로 이은 형태로 통일됩니다.
  기존 세 필드는 그대로라 응답을 읽는 쪽에서 조치할 것은 없습니다. → [내부 API](/policy/ops/internal-api)

### 문서

- **정책 엔진이 심사하는 세 영역을 이름으로 부릅니다.** 설계 초안의 표 행 번호 「도메인 ①②③」 대신
  서명 연산·어드민 액션·정책 변경 액션입니다. 세 용어를 [용어](/concepts/terminology)에 실었고, 결정 색인·
  로드맵·API 계약 주석에서 번호 표기를 없앴습니다. 날짜가 박힌 결정 이력과 동결 문서는 그대로입니다.
