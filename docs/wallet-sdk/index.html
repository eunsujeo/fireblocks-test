자금 흐름

고객별 입금 주소에 들어온 자산은 온체인 확정 뒤에도 동결 상태입니다. 파트너가 심사하고 Sweep을 요청하면 지정한 WorkspaceVault로 옮겨집니다. 고객 출금은 WorkspaceVault에서 외부 주소로 나가는 별도 요청입니다.

주소 발급고객별 입금 주소AccountWallet→입금·집금확정 → 동결 → Sweep파트너 심사 후 이동→내부 보관WorkspaceVault용도는 파트너가 정의→고객 출금외부 수취 주소정책 판단과 서명 대조

WorkspaceVault의 용도는 파트너가 정합니다. 집금용·출금용 지갑을 어떻게 배치할지, 핫·콜드와 고객·회사 자산을 어떻게 나눌지는 별도로 설계해야 합니다.

참고: 입금 (Deposit) ↗ · 집금 (Sweep) ↗ · 출금 (Withdrawal) ↗ · 지갑 계층 ↗
