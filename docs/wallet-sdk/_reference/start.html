시작하기

첫 요청에서 자금 이동까지, 파트너사 개발자가 읽는 순서

Wallet SDK 는 파트너 대상 API 로 붙입니다. 이 탭은 그 API 를 처음 부르는 사람이 어느 순서로 무엇을 읽으면 되는지를 안내하고, 어느 영역에도 속하지 않는 색인 둘을 함께 둡니다. Wallet SDK 가 무엇을 맡고 무엇을 맡지 않는지는 홈에 있습니다.

붙이는 순서

이 탭의 페이지 둘을 위에서 아래 순서로 읽습니다.

  • 첫 요청: 계정 하나를 만들고 그 계정의 입금 주소를 받기까지입니다. 여기까지 오면 나머지는 자금이 움직이는 이야기입니다.
  • 표면과 인증: 어떤 API 를 누가 부르고, 격리 스코프가 인증에서 어떻게 나오는지입니다. 요청이 스코프를 싣지 않는 이유가 여기 있습니다.

그다음은 계정과 지갑 탭으로 넘어갑니다. 탭 여섯의 전체 안내는 홈에 있습니다.

색인 둘

  • 용어 — 어느 말이 무엇을 가리키는지의 색인입니다. 낱말마다 한 줄 정의와 자세한 설명이 있는 페이지를 함께 알려 줍니다.
  • 규제 대응 — 접속기록·개인정보·보존·암호키 통제가 어느 페이지에 있는지의 색인입니다.
