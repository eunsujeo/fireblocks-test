참고 문서

v0.5.0

문서

  • 계정 계층의 정의를 바로잡았습니다. Workspace는 Wallet SDK를 도입한 회사 하나, Tenant는 그 회사가 운영하는 서비스 하나입니다. 카카오페이와 발행 시스템 두 예시 표를 계정 계층에 넣었고, 「고객사와 파트너사는 같은 것」 절은 그 표로 요약했습니다.
  • 첫 요청 전에 생기는 층을 셋으로 갈랐습니다. 플랫폼이 여는 것(워크스페이스·네트워크), 운영자가 등록하는 것(테넌트·API 키·토큰·vault), 파트너사가 받는 것(API 키 원문) — 첫 요청.
  • 토큰 단위 지갑의 이유를 고쳤습니다. 비EVM 확장과 토큰 상태 차단 둘이고, “토큰마다 다른 주소” 수요는 뺐습니다. 같은 페이지의 「미등록 토큰의 입금」 절 제목을 바꿨습니다 — 지갑 계층.
  • 주소록이 입금에도 붙습니다. 입력이 아니라 관측으로 — 입금 확정 통지의 sourceRegistered가 그것입니다. 도메인 모델의 옛 서술을 고쳤습니다.
  • 카탈로그는 Network·Token 정의만 남겼습니다. Asset 미도입 절을 뺐습니다 — 카탈로그.
  • 홈의 「같은 법인」 절과 인증 페이지의 서비스 간 인증 절을 뺐습니다. 운영자 인증은 세션과 2단계 인증으로 다시 썼고, 콘솔이 Wallet 서버를 거친다는 것을 명시했습니다 — 표면과 인증.
  • “유입”을 “입금”으로 통일했습니다. 출금과 짝이 되는 말이고 이동 종류의 이름과도 같아서, 사이트 본문 80곳을 바꿨습니다. 용어 표의 항목도 입금으로 옮겼습니다.
