참고 문서

Wallet Policy Engine Internal API

OpenAPI 명세 내려받기openapi.PolicyApi.yaml

Version 0.0.0

Admins

어드민 신원·역할 디렉토리.

  • GET
    어드민 목록 조회/admins
  • POST
    어드민 초대/admins

Approvals

maker-checker 승인. 정족수 obligation의 이행 표면이고, 요청자와 승인자는 같을 수 없다.

  • GET
    승인 대기 목록 조회/approvals
  • POST
    승인 표 제출/request/{policyRequestId}/approvals

Admin Auth

어드민 인증. 챌린지 모델로 2FA를 수집한다.

  • POST
    2FA 검증/auth/2fa
  • POST
    2FA 자가 등록/auth/enrollments
  • POST
    2FA 등록 확인/auth/enrollments/confirm
  • POST
    어드민 로그인/auth/login
  • POST
    어드민 로그아웃/auth/logout
  • GET
    세션 신원 조회/auth/session

Bundle Serving

OPA 사이드카가 활성 번들을 당겨 가는 표면. 자격은 서비스 크리덴셜이다.

  • GET
    활성 번들 tarball 내려받기/bundles/{bundleName}.tar.gz
  • GET
    활성 번들 조회 (서빙)/bundles/{bundleName}/active

Callback

서명 인프라 콜백. 서명 이전의 마지막 관문이다.

  • POST
    Co-Signer pre-signing 콜백/callback/fireblocks-cosigner

PIP Source Kinds

PIP 소스 종류 카탈로그.

  • GET
    PIP 소스 종류 목록 조회/pip-source-kinds

Partner

비동기 PIP 결과 제출. 아웃바운드 트리거에 대한 인증된 인바운드다.

  • POST
    PIP 결과·이행 증거 제출/pip/{policyDataRequestId}/result

Bootstrap

초기 어드민 등재. 온보딩 런북의 첫 단계다.

  • POST
    초기 어드민 계정 생성/platform/bootstrap/admins

Policy Bundle

정책 로직 번들 발행·활성화. 플랫폼 거버넌스가 소유한다.

  • POST
    번들 활성화/platform/policy-bundles/activations
  • GET
    활성 번들 조회/platform/policy-bundles/activations/{bundleName}
  • GET
    발행 승인 목록/policy-bundles/approvals
  • POST
    발행 승인 레코드 개설/policy-bundles/approvals
  • GET
    발행 승인 레코드 상세 조회/policy-bundles/approvals/{publicationApprovalId}
  • POST
    발행 승인 표 제출/policy-bundles/approvals/{publicationApprovalId}/votes
  • POST
    번들 발행/policy-bundles/publications

Workspace Registration

워크스페이스 등록과 매니저 관리. platform 문 전용이다.

  • GET
    워크스페이스 목록 조회/platform/workspaces
  • POST
    워크스페이스 등록/platform/workspaces
  • POST
    스텝업 챌린지 발급/platform/workspaces/challenges
  • GET
    워크스페이스 상세 조회/platform/workspaces/{workspaceId}
  • POST
    워크스페이스 매니저 지명/platform/workspaces/{workspaceId}/managers
  • POST
    워크스페이스 매니저 등록 토큰 재발급/platform/workspaces/{workspaceId}/managers/{adminUserId}/enrollment-tokens
  • POST
    워크스페이스 매니저 회수/platform/workspaces/{workspaceId}/managers/{adminUserId}/revoke

Policy Draft

룰 저작. 컴파일 검증을 지나야 발행 후보가 된다.

  • GET
    draft 목록/policy-drafts
  • POST
    draft 생성/policy-drafts
  • GET
    편집기 base 조회/policy-drafts/baseline/{bundleName}
  • GET
    revision 조회 (주소)/policy-drafts/revisions/{revisionId}
  • GET
    draft 조회/policy-drafts/{draftId}
  • POST
    draft 폐기/policy-drafts/{draftId}/discard
  • POST
    revision 추가/policy-drafts/{draftId}/revisions
  • GET
    revision 조회/policy-drafts/{draftId}/revisions/{revisionId}
  • POST
    revision 검증 실행/policy-drafts/{draftId}/revisions/{revisionId}/validation

Request

정책 판단 요청 접수와 조회. 202 접수 후 비동기 평가다.

  • POST
    판단 요청 접수/request
  • GET
    판단 요청 조회/request/{policyRequestId}

Workspace Bundle

워크스페이스 번들 발행·활성화. 고객사가 자기 정책을 저작한다.

  • GET
    활성 워크스페이스 번들 조회/workspace-bundles/activation
  • POST
    워크스페이스 번들 활성화/workspace-bundles/activations
  • POST
    워크스페이스 번들 발행/workspace-bundles/publications
