계정 상세 조회

accountId로 계정을 상세 조회한다. 상태로 걸러내지 않으므로 비활성 계정도 status와 함께 반환한다.

Errors:

  • 404 ACCOUNT_NOT_FOUND: accountId로 매칭되는 계정 없음
GET/api/v1/accounts/{accountId}
