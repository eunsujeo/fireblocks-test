세션 신원 조회

세션이 증명하는 신원 조회. 자격은 Bearer 헤더 또는 세션 쿠키다(PolicyAdminSessionAuth). 만료·변조 토큰은 401이고 봉투는 위 둘과 같다. 콘솔은 기동 시 이것으로 쿠키 세션을 되살린다.

인가 판정의 입력을 콘솔이 직접 볼 수 있게 하는 자리다 — 어드민 액션의 인가는 여기 실린 grants로 판정된다.

Errors:

  • 401 AUTHENTICATION_FAILED: 세션이 확정되지 않았다. 계정의 소속이 이 문과 어긋난 경우도 여기다

codePolicyErrorCoderequired
policy 표면이 내는 `error.code`의 전량. 표면 enum의 합집합에 프레임워크 코드를 더한 것이고, 이 union이 `PolicyApiErrorResponse`의 `code` 타입이다. **wallet 도메인 `ErrorCode`(루트 common.tsp)와 섞이지 않는 것이 계약이다** — 두 값 집합은 겹치는 것이 `INTERNAL_ERROR` 하나뿐이라, 한 봉투로 묶으면 레퍼런스를 읽는 소비자가 policy 응답에서 결코 나오지 않는 코드 마흔여덟 개를 분기 대상으로 받는다. 새 표면 enum을 만들면 여기에 더한다. 더하지 않으면 그 코드는 응답 타입 어디에도 연결되지 않아 생성 스키마에 나타나지 않는다.
