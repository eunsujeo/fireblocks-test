Wallet API

OpenAPI 명세 내려받기openapi.WalletApi.yaml

Version 0.0.0

Accounts

파트너사의 최종 사용자를 wallet 안에서 대리하는 계정. 삭제 없이 활성·비활성만 전환한다.

  • GET
    계정 referenceId 조회/api/v1/accounts
  • POST
    계정 생성/api/v1/accounts
  • GET
    계정 상세 조회/api/v1/accounts/{accountId}
  • POST
    계정 상태 변경/api/v1/accounts/{accountId}/status

Account Wallets

계정에 귀속된 토큰별 입금 지갑. 온체인 주소가 여기 붙는다.

  • GET
    계정 지갑 목록 조회/api/v1/accounts/{accountId}/account-wallets
  • POST
    계정 지갑 생성/api/v1/accounts/{accountId}/account-wallets
  • GET
    계정 지갑 상세 조회/api/v1/accounts/{accountId}/account-wallets/{accountWalletId}

Address Books

출금 목적지 등록. 등재 여부는 거절 사유가 아니라 정책 입력이다.

  • GET
    주소록 목록 조회/api/v1/accounts/{accountId}/address-books
  • POST
    주소록 등록 (지갑 소유 증명 nonce 서명 포함)/api/v1/accounts/{accountId}/address-books
  • POST
    주소록 등록용 지갑 소유 증명 nonce 발급/api/v1/accounts/{accountId}/address-books/nonce
  • GET
    주소록 상세 조회/api/v1/accounts/{accountId}/address-books/{addressBookId}
  • DELETE
    주소록 삭제/api/v1/accounts/{accountId}/address-books/{addressBookId}

Deposits

온체인 관측으로 기록된 유입. 확정되면 기본 동결로 들어간다.

  • GET
    입금 내역 목록 조회/api/v1/accounts/{accountId}/deposits
  • GET
    입금 내역 상세 조회/api/v1/accounts/{accountId}/deposits/{depositId}

Withdrawals

workspace vault에서 외부 주소로의 출금. 자금 귀속에 따라 표면이 갈린다.

  • GET
    출금 내역 목록 조회/api/v1/accounts/{accountId}/withdrawals
  • POST
    출금 요청/api/v1/accounts/{accountId}/withdrawals
  • GET
    출금 내역 상세 조회/api/v1/accounts/{accountId}/withdrawals/{withdrawalId}

Networks

블록체인 네트워크 카탈로그. 계열에 따라 주소 체계가 갈린다.

  • GET
    네트워크 목록 조회/api/v1/networks
  • GET
    네트워크 상세 조회/api/v1/networks/{networkId}

Sweeps

동결 유입 건을 지목해 집금 vault로 옮긴다. 해제와 이동이 원자적이다.

  • GET
    스윕 referenceId 조회/api/v1/sweeps
  • POST
    스윕 요청 생성/api/v1/sweeps
  • GET
    스윕 상세 조회/api/v1/sweeps/{sweepId}

Tokens

네트워크 위의 자산. 유일성은 (workspace, network, 컨트랙트 주소)에서 성립한다.

  • GET
    토큰 목록 조회/api/v1/tokens
  • GET
    토큰 상세 조회/api/v1/tokens/{tokenId}

Travel Rules

트래블룰 정보 교환. 판단 주체는 wallet이고 상대 VASP에는 단일 boolean만 낸다.

  • GET
    트래블룰 대상 VASP 목록 조회/api/v1/travel-rules/vasps

Workspace Vault Transfers

workspace vault 사이의 자산 이동. 동결되지 않은 자산만 움직인다.

  • GET
    워크스페이스 Vault 이체 referenceId 조회/api/v1/workspace-vault-transfers
  • POST
    워크스페이스 Vault 이체 요청 생성/api/v1/workspace-vault-transfers
  • GET
    워크스페이스 Vault 이체 상세 조회/api/v1/workspace-vault-transfers/{workspaceVaultTransferId}
