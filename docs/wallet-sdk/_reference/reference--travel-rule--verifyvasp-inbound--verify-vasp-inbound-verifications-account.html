타 VASP에서 주소 검증 요청

수취 계좌 검증(inbound). 결과는 로그만 남기고 저장하지 않는다.

POST/api/v1/verifyvasp/verifications/account

Authorization

AuthorizationBearer token · headerrequired

Request body

requiredapplication/json
originatingVaspIdstringrequired
symbolstringrequired
versionstringrequired
ivms101objectrequired
networkstring

Responses

200The request has succeeded.
accountVerificationResultstringrequired
verifiedAtstringrequired
reasonstring
defaultAn unexpected error response.
errorApiErrorDetailrequired
Show propertiesHide properties
codestringrequired
SCREAMING_SNAKE_CASE (예: NOT_FOUND, INVALID_REQUEST, UNAUTHORIZED, INVALID_STATE).
messagestringrequired
detailsany
validation 실패 시 field→message 맵 등. 필요할 때만 채워진다.

Request

cURL
curl -X POST "/api/v1/verifyvasp/verifications/account" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "originatingVaspId": "string",
  "symbol": "string",
  "version": "string",
  "ivms101": {},
  "network": "string"
}'
JavaScript
const response = await fetch("/api/v1/verifyvasp/verifications/account", {
