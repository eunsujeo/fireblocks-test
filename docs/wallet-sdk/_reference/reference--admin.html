Wallet Admin API

OpenAPI 명세 내려받기openapi.WalletAdminApi.yaml

Version 0.0.0

Approvals

maker-checker 승인. 정족수 obligation의 이행 표면이고, 요청자와 승인자는 같을 수 없다.

  • GET
    승인 진행 내역 목록 조회/admin/api/v1/approvals
  • GET
    승인 진행 내역 상세 조회/admin/api/v1/approvals/{approvalId}
  • POST
    단건 승인/admin/api/v1/approvals/{approvalId}

Auth

어드민 인증. 세션과 2FA를 다룬다.

  • POST
    2FA 인증/admin/api/v1/auth/2fa
  • POST
    2FA OTP 등록/admin/api/v1/auth/2fa/register
  • POST
    유저 가입 (초대 수락)/admin/api/v1/auth/join
  • POST
    로그인/admin/api/v1/auth/login

Networks

블록체인 네트워크 카탈로그. 계열에 따라 주소 체계가 갈린다.

  • GET
    네트워크 목록 조회/admin/api/v1/networks
  • GET
    네트워크 상세 조회/admin/api/v1/networks/{networkId}
  • POST
    네트워크 상태 변경/admin/api/v1/networks/{networkId}/status

    Policy 상세 조회/admin/api/v1/policies/{policyId}

Tenants

  • GET
    테넌트 목록 조회/admin/api/v1/tenants
  • POST
    테넌트 생성/admin/api/v1/tenants

    테넌트 상세 조회/admin/api/v1/tenants/{tenantId}
  • POST
    테넌트 상태 변경/admin/api/v1/tenants/{tenantId}/status

API Keys

  • GET
    API Key 목록 조회/admin/api/v1/tenants/{tenantId}/api-keys
  • POST
    API Key 생성/admin/api/v1/tenants/{tenantId}/api-keys
  • GET
    API Key 상세 조회/admin/api/v1/tenants/{tenantId}/api-keys/{apiKeyId}

  • POST
    API Key 상태 변경/admin/api/v1/tenants/{tenantId}/api-keys/{apiKeyId}/status
