참고 문서

v0.8.0

문서

  • 정책 엔진 탭을 질문 축의 네 섹션으로 재편했습니다 — 룰(/policy/rule/*) · 저작과 발행(/policy/authoring/*) · 평가 런타임(/policy/runtime/*) · 계약과 운영(/policy/ops/*). 열여섯 페이지의 URL이 움직였고 옛 주소는 전부 새 주소로 이동합니다. 「룰의 일생」 그룹은 해체되어 각 섹션에 들어갔습니다.
  • 모듈 결합(AND/OR)은 결정과 결합으로, 금액 리터럴 비교 규칙은 룰 명세로 옮겼습니다. 번들 페이지는 번들과 발행 경로만 남습니다.
  • 평가의 순간의 조건 3치 서술을 기준 문서에 맞춰 정정했습니다 — 미지는 입력에 없는 PIP 소스를 가리켰을 때만 나오고, 요청의 빈 필드 비교는 거짓입니다.
